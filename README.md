# Kiran Kumar C S

Portfolio of Kiran Kumar C S, a Python full stack developer based in Thrissur, Kerala.

Live site: https://kiran-profe.github.io/portfolio/

## What’s in this folder

- `index.html` — the page GitHub Pages serves
- `Main.dc.html` — the same portfolio page
- `assets/` — portrait
- `support.js` and `vendor/` — scripts the page needs to run

## View it on your computer

```bash
python3 -m http.server
```

Open http://127.0.0.1:8000/
